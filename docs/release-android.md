# Android 출시 준비 (GDD Phase 5)

작성 2026-10-14. 코드로 할 수 있는 부분은 끝났고, **계정·법적 판단이 필요한 부분은 개발자(사용자)가 직접** 해야 한다. 아래 ☐는 사람이 할 일.

## 1. 빌드

```bash
npm run android:debug        # 웹 빌드 → cap sync → android/app/build/outputs/apk/debug/app-debug.apk
npm run android:open         # Android Studio로 열기 (서명·번들 빌드는 여기서)
```

- 구성: Capacitor 8 (`capacitor.config.json`, appId `app.pokerdefense`), 세로 고정, 몰입 모드(상태·내비 바 숨김, `MainActivity.java`).
- TypeScript 7은 `capacitor.config.ts`를 못 읽어서 JSON 설정을 쓴다.
- 확인한 것(에뮬레이터 API 35): 실행·로비·캠페인, 보상형 테스트 광고 시청 → 보상 지급(교환 +1), 다음 광고 미리 불러오기, 뒤로 가기(게임: 두 번 → 로비 / 로비: 두 번 → 종료 / 대전: 기권 확인 창).

## 3. ⚠ 등급 분류 — GDD의 기존 문구를 그대로 쓰면 안 된다

GDD Phase 5에는 "포커는 족보만 차용·**베팅 없음** → 사행성 아님으로 기재"라고 적혀 있지만, **v1.6 이후 1:1 대전에 판돈 걸기(앤티·레이즈·콜·폴드)가 들어갔다.** 판돈은 판 안에서만 도는 게임 골드이고 현금·유료 재화로 바꿀 수 없지만, 등급 설문(IARC)의 "모의 도박(simulated gambling)" 질문에 해당할 가능성이 높다. 거짓으로 답하면 앱 삭제·계정 제재 사유가 된다.

판단에 필요한 사실 (설문 답변은 개발자가 직접 판단):
- 판돈은 매치 안의 골드만 오간다. 현금·다이아·아이템으로 바꿀 수 없고 매치가 끝나면 사라진다.
- 다이아(유료 판매 예정)로 사는 메타 업그레이드 중 "시작 골드 +100"이 있다. 랭크 대전은 메타 미적용이지만, **친구 대전은 방장이 "메타 적용"을 켜면 이 골드가 판돈에 쓰일 수 있다.** 유료 재화가 판돈 크기에 영향을 주는 경로이므로 출시 전 막을지 결정 필요.
- 포커 족보·카드 이미지 사용, 실제 포커 게임 진행은 없음(디펜스).
- 선택지: (a) 설문에 모의 도박 요소 있음으로 답하고 등급을 받는다, (b) 판돈 걸기를 출시 빌드에서 끈다(`duel.json`/방 규칙 기본값), (c) 전문가 확인 후 결정.

## 4. 개인정보·데이터 보안 (Play 필수)

☐ 개인정보처리방침 URL이 필요하다 (AdMob 사용 + 계정 데이터). 앱이 실제로 다루는 것:
- 광고 ID·기기 정보: AdMob(Google)이 광고·측정에 사용. 동의(UMP)는 필요한 지역에서 자동으로 묻는다 — 한국 에뮬레이터에서는 "필요 없음"으로 나왔다.
- 익명 계정 ID(Supabase Auth), 닉네임, 대전 기록·입력 로그·레이팅·친구 목록: 서버(Supabase 서울 리전)에 저장.
- 기기 저장(localStorage): 메타 진행·설정·이어하기. 다이아 잔액은 기기에만 있음 → 앱 삭제 시 사라짐(안내 필요).
- 계정(익명 계정 포함)을 만드는 앱은 Play 정책상 계정 삭제 방법을 안내해야 할 수 있다 — 지금 앱 안에 계정 삭제 기능은 없다(☐ 적용 여부 확인 후 추가).

## 5. Play Console 순서 (☐ 전부 개발자 계정에서)

1. 개발자 계정(등록비) → 앱 만들기 → 앱 ID 확정
2. 개인정보처리방침 URL, 데이터 보안 설문, 광고 포함 "예", 대상 연령, 등급 설문(§3)
3. 내부 테스트 트랙에 AAB 업로드 → 본인 기기로 설치 확인
4. 비공개 테스트 트랙 + 테스터 이메일 목록(지인 10~20명). 신규 개인 개발자 계정은 **비공개 테스트 12명 이상·14일 이상**을 거쳐야 프로덕션 신청이 가능하다(Play 정책, 신청 전 최신 조건 확인)

## 7. 알려진 제한

- 60fps: 에뮬레이터(소프트웨어 렌더링)로는 측정 불가. 실기기 제보(설정 → 프레임 표시)로 확인한다.
- 폰트: Google Fonts를 네트워크로 불러온다. 오프라인에선 기본 글꼴로 보인다 (번들링은 폰트 파일 다운로드 승인 후).
- 화면비: 1080×1920 고정 비율이라 20:9 폰에서는 위아래에 남색 여백이 생긴다.
- 광고 불러오기: 앱 시작 시 미리 불러오고, 실패하면 10·30·60·120초 간격으로 다시 시도. 누를 때 준비가 안 됐으면 15초까지만 기다리고 "광고를 불러오지 못했어요" 안내.
