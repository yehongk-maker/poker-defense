# 시너지 확장 설계안 — 종족·진형 축 추가

작성일: 2026-09-21 | 상태: **1~3단계 구현됨** (종족 4종·사거리 진형 4종·위치 시너지 2종·인접 오라, 2026-09-21) | 관련: GDD 3.2.3 / 3.6

## 0. 한 줄 요약

지금은 **수트(진영) + 클래스(역할)** 2축이다. 여기에 **종족(휴먼·고블린·몬스터·정령)** 과 **진형(근접·원거리·위치)** 2축을 더해 **4축 시너지**로 만든다.
각 축은 서로 다른 방향으로 유닛을 묶어서, 같은 5장 패로도 "어느 축을 밀지"가 매번 달라지게 한다.
새로 넣는 효과는 전부 **이번에 바뀐 룰(사거리·배치·제한 시간)** 을 건드리는 "질적" 보상이라, 숫자 버프만 쌓이는 시너지가 되지 않게 한다.

| 축 | 묶는 기준 | 카운트 방식 | 컨셉 | 상태 |
|---|---|---|---|---|
| 진영 (수트) | ♠♥♦♣ | 기수 (중복 포함) 2/4/6 | 순수 빌드 보상 | 구현됨 |
| 역할 (클래스) | 약탈자·파괴병기·성령체·술법체·초월체 | 종류 수 2/4 | 혼합 빌드 보상 | 구현됨 |
| **종족** | 휴먼·고블린·몬스터·정령 | 기수 3/5/7 (정령은 2/3) | "누구를 모으나" | **신규** |
| **진형** | 근접(사거리 2)·중거리(3)·원거리(4) + 위치 | 기수 3/6, 위치 조건 | "어디에 두나" | **신규** |

## 1. 종족(Race) 축

### 1.1 종족 배정 — 20종 + 영웅 8종

수트·클래스와 **다른 방향으로** 잘라야 조합이 늘어난다. 원칙: 한 수트 안에 종족이 2~3개 섞이고, 한 종족이 수트 3개 이상에 걸친다.

| 유닛 | 수트 | 티어 | 클래스 | **종족** | 배정 근거 |
|---|---|---|---|---|---|
| 창격병 | ♠ | 1 | 약탈자 | 휴먼 | 병사 |
| 쌍도끼 전사 | ♠ | 2 | 파괴병기 | 휴먼 | 용병 |
| 파쇄 기수 | ♠ | 3 | 파괴병기 | 휴먼 | 기병 |
| 흑철 기사 | ♠ | 4 | 파괴병기 | 휴먼 | 기사 |
| 강철 거신 | ♠ | 5 | 초월체 | 몬스터 | 거대 골렘 |
| 견습 사제 | ♥ | 1 | 성령체 | 휴먼 | 수도자 |
| 성가대원 | ♥ | 2 | 성령체 | 휴먼 | 수도자 |
| 빛의 치유사 | ♥ | 3 | 성령체 | 정령 | 빛의 화신 |
| 대성전 기사 | ♥ | 4 | 성령체 | 휴먼 | 성기사 |
| 세라핌 | ♥ | 5 | 초월체 | 정령 | 천상체 |
| 광부 | ♦ | 1 | 약탈자 | 고블린 | 땅굴꾼 |
| 동전 투척수 | ♦ | 2 | 약탈자 | 고블린 | 잡상인 |
| 보석 사수 | ♦ | 3 | 술법체 | 고블린 | 보석 기술자 |
| 금고 골렘 | ♦ | 4 | 파괴병기 | 몬스터 | 골렘 |

영웅은 **종족 카운트에 +1로 포함**한다(수트·클래스 카운트는 기존대로 제외). 영웅 선택이 종족 빌드 방향을 정하게 만드는 장치다.

| 영웅 | 수트 | 종족 |
|---|---|---|
| 검은 대공 / 강철 파멸기 | ♠ | 휴먼 / 몬스터(기계 거병) |
| 수호 현자 / 태산 수호자 | ♥ | 휴먼 / 몬스터(암석 거인) |
| 황금 저격수 / 도굴왕 | ♦ | 휴먼 / 고블린 |
| 심연 군주 / 뇌운 폭군 | ♣ | 몬스터 / 정령(뇌운의 정령) |

### 1.2 종족 시너지 효과

임계값은 **기수(중복 포함)** 기준이다. 클래스가 "종류 수"로 합성을 유도하니, 종족은 반대로 "머릿수"를 세서 물량 빌드에도 길을 열어 준다.

**휴먼 — 「대열」 (규율·진형 종족)** 3 / 5 / 7기
- 3기: 같은 행 또는 같은 열에 있는 휴먼 유닛 1기당 공격력 +4% (자기 제외, 최대 +16%)
- 5기: 위 효과 +6%/기, 휴먼 공속 +8%
- 7기: 「방진」 — 가장자리 칸의 휴먼 유닛 사거리 +1 (근접 2→3: 모서리에서 두 변을 다 커버)
- 의도: 배치 축과 직접 연결. 휴먼을 일렬로 세우면 강해지므로 "줄 맞추기"가 플레이가 된다.

**고블린 — 「약탈」 (경제·속공 종족)** 3 / 5기
- 3기: 처치 골드 +1, 웨이브 시작 시 골드 +10
- 5기: 고블린 공속 +15%, **시간 초과로 이탈한 적 1기당 골드 +8** (라이프 손실을 돈으로 일부 보전 — 고블린 빌드는 "지는 대신 부자")
- 의도: 새 제한 시간 룰의 손실을 다른 자원으로 바꿔 주는 유일한 축. 부활 광고·업그레이드 구매력과 연결된다.

**몬스터 — 「위압」 (거대·광역 종족)** 2 / 4 / 6기
- 2기: 몬스터 유닛 광역 반경 +15%
- 4기: 적 전체 이동 속도 -8% (트랙에 오래 머물러 사거리 안에 더 자주 들어옴)
- 6기: 「포효」 — 웨이브 시작 시 3초간 적 전체 기절 (스폰 구간 압축 → 광역 극대화)
- 의도: 몬스터는 티어 4~5에 몰려 있어 후반 빌드. 광역·CC로 "많은 적"을 상대하는 방향.

**정령 — 「가호」 (희소·시간 종족)** 2 / 3기
- 2기: **웨이브 제한 시간 +4초**
- 3기 (영웅 포함해야 가능): 제한 시간 +8초, 웨이브 종료 시 라이프 1 회복 (♥6과 중복 시 합산)
- 의도: 제한 시간 룰을 건드리는 유일한 축. 정령 2기(빛의 치유사+세라핌 또는 영웅)는 나오기 어렵지만 나오면 판이 편해진다.

## 2. 진형(Formation) 축 — 사거리와 위치

유닛 데이터에 태그를 추가하지 않고, **이미 있는 `range`와 `slot`으로 자동 판정**한다. 플레이어가 배치를 바꾸는 즉시 시너지가 바뀌는 게 핵심이다.

### 2.1 사거리 계열 시너지 (기수 기준)

**근접 편성 — 「전열」** 사거리 2 유닛 3 / 6기
- 3기: 근접 유닛 공격력 +10%
- 6기: 근접 유닛 공격력 +20%, **근접 사거리 +1** (2→3). 안쪽 8칸에서도 트랙에 닿게 되어 가장자리 16칸 병목이 풀린다.

**원거리 편성 — 「후열」** 사거리 4 유닛 3 / 6기
- 3기: 원거리 공속 +10%
- 6기: 원거리 공속 +20%, 사거리 페널티 완화 (rangeDamageMult 4: ×0.75 → ×0.9)

**중거리 편성 — 「중열」** 사거리 3 유닛 3기
- 3기: 디버프 지속 +25%, 광역 반경 +10% (마법 유닛이 대부분 사거리 3)

**혼성 — 「전후열 완성」** 근접 ≥3 **그리고** 원거리 ≥3
- 전체 공격력 +8%, 전체 공속 +5%
- 의도: 한 계열만 몰면 그 계열의 6기 보너스가 크고, 섞으면 넓고 얕은 보너스. 둘 다 정답이 되게.

### 2.2 위치 시너지 (슬롯 기준)

**「모서리 수비」** 모서리 4칸(0, 4, 20, 24)이 전부 근접 유닛
- 모서리 유닛 공격력 +15%. 모서리는 두 변을 동시에 커버하는 최고 자리라, 채우면 확실히 보상.

**「밀집 방진」** 2×2 블록 4칸이 같은 수트
- 해당 4기 공격력 +10%. 수트 축과 위치 축을 이어 준다.

**「인접 오라」 (기존 오라 유닛의 실체화)**
- 성가대원(인접 4칸 공격력 +8%), 견습 사제(주변 공속 +3%)는 지금 "전체 적용"인데, 슬롯이 생겼으니 **실제 인접 칸에만** 적용하도록 바꾼다. 오라 유닛을 어디에 두느냐가 플레이가 된다.

## 4. 밸런스 원칙

1. **한 축의 최대 구간에는 숫자가 아니라 "룰 변화"를 준다.** 사거리 +1, 제한 시간 +초, 이탈 골드, 웨이브 시작 기절. 숫자 버프만 4축이면 곱연산으로 터진다.
2. **합산 상한**: 공격력 +% 계열은 모든 축 합쳐 +80%까지, 공속은 +50%까지 캡. 그 위는 룰 변화만 남긴다.
3. **종족은 기수, 클래스는 종류**로 세서 합성(3→1)과 물량이 서로 다른 축에서 보상받게 한다. 합성하면 클래스는 유지되고 종족 기수는 줄어드는 긴장.
4. **정령·혼성처럼 "안 지게 해 주는" 시너지는 딜 시너지보다 작게**. 부활 광고 자리(GDD 9.2)를 침범하지 않도록.
5. 시뮬레이터 봇에 빌드 전략(축 고정 봇)을 추가해서 축별 도달 웨이브가 ±3 안에 들어오게 튜닝.

### 5.2 코드 (systems/)

| 신규 effect type | 어디서 소비 | 필요한 변경 |
|---|---|---|
| `line_attack_pct` | SynergySystem | 같은 행/열 종족 아군 수 계산 (slot 기반) → attackPctBonus |
| `range_plus` | Battle | `DeployedUnit.rangeBonus` 추가, `inRange(slot, def.range + rangeBonus)` |
| `time_limit_plus` | Battle | `BattleOptions.timeLimitBonus` → timeLimit에 가산 |
| `leak_gold` | GameLoop | `ev.leaked × amount` 골드 지급 |
| `wave_start_gold` | GameLoop.startCombat | 골드 가산 |
| `enemy_speed_pct` | Battle | 전역 이속 배율 옵션 |
| `wave_start_stun` | Battle | 스폰된 적에 stunUntil 부여 |
| `range_mult_override` | Battle | rangeDamageMult 덮어쓰기 옵션 |
| 위치 조건(corners/block/line) | SynergySystem | slot 배열을 받아 판정 — 이미 `DeployedUnit.slot` 있음 |
| 인접 오라 | SynergySystem | `aura_*`의 `area: adjacent/adjacent4`를 실제 인접 슬롯으로 |

전부 순수 로직 + JSON이라 씬 변경은 HUD 시너지 목록(축별 아이콘·탭 상세)뿐이다.

### 5.3 UI

- HUD 시너지 줄을 4축으로 나눠 표시: `♠4 · 파괴병기2 · 휴먼5 · 전열3`
- 정비 페이즈에 유닛을 옮기면 진형 시너지가 즉시 갱신되어 배치 실험이 보상받는 느낌을 준다.
- 스와이프 화면에 "시너지 도감" 섹션(발동 조건·현재 카운트) 추가.

## 6. 구현 순서 제안

1. **종족 태그 + 종족 시너지 4종** (숫자 효과부터: 휴먼 대열, 고블린 골드, 몬스터 광역, 정령 시간) — JSON + SynergySystem, 테스트
2. **사거리 진형 3종 + 혼성** — range 기반 자동 판정, `range_plus`는 Battle 변경 포함
3. **위치 시너지 + 인접 오라 실체화** — slot 기반 판정
4. **시뮬 봇 확장**: 축 고정 봇(휴먼/고블린/몬스터/혼성)으로 축별 도달 웨이브 측정 → 임계값·수치 조정
5. HUD 4축 표시, 시너지 도감

1~2단계만 해도 "종족·사거리 시너지"는 완성이고, 3단계가 배치 재미의 핵심이다.
