# 🃏 포커디펜스 (Poker Defense)

> 카드 5장으로 포커 족보를 만들어 유닛을 소환하는 **모바일 세로형 랜덤 디펜스 게임**.
> 기획서(GDD)부터 클라이언트·서버·Android 빌드까지 1인 개발.

## 게임 소개

매 라운드 카드 5장을 받고, 한 번 교환해서 족보를 완성합니다. 족보가 높을수록 강한 유닛이 소환되고,
유닛 조합에 따라 시너지가 붙습니다. 몰려오는 적 웨이브를 막아내면 됩니다.

- **유닛 40종**: 지상·공중 구분, 유닛별 사거리
- **시너지 4축 + 빙고 보너스**: 같은 계열을 모을수록 강해지는 빌드 설계
- **영웅 & 메타 성장**: 족보별 영웅 조각 수집, 영구 업그레이드, 도감
- **행운 드로우**: 아웃(필요한 카드) 수에 따라 가중 추첨되는 교환 보조
- **1:1 레이스 + 판돈 걸기**: 체크·레이즈 → 콜·폴드로 이어지는 포커식 베팅
- **3방향 스와이프 UI**: 상점 / 족보·시너지 정보 / 상대 현황

## 온라인 대전

| 모드 | 내용 |
|---|---|
| 랭크전 | 실시간 매칭, ELO-lite 레이팅, 티어·시즌 보상 |
| 친구 대전 | 방 코드·초대 링크, 방 규칙 설정, 관전 |
| 고스트전 | 다른 플레이어의 기록을 상대로 비동기 대전 |

기권·재접속·관전을 지원합니다.

## 기술적으로 고민한 부분

### 1. 결정론 시뮬레이션과 입력 로그
게임 로직(`src/systems/`)은 Phaser에 의존하지 않는 **순수 TypeScript**입니다. 시드 난수를 라운드별 스트림으로 나누고
플레이어 입력만 기록하기 때문에, 같은 시드와 입력 로그만 있으면 한 판 전체를 똑같이 재생할 수 있습니다.
리플레이, 고스트전, 재접속 복원이 모두 이 구조 위에서 동작합니다.

### 2. 서버 측 결과 검증
클라이언트가 보낸 결과를 믿지 않습니다. 같은 게임 로직을 Supabase Edge Function(`verify-match`)으로 번들해,
서버에서 입력 로그를 다시 재생하고 승패를 확인합니다.

### 3. 손패 정보 비밀화
처음에는 손패 난수를 "매치 시드 + 플레이어 id + 라운드"로 만들었는데, 상대가 이 값을 모두 알 수 있어
클라이언트를 고치면 내 손패를 계산할 수 있는 구멍이 있었습니다. 매치마다 플레이어별 비밀 키를 서버가 발급하고
RLS로 본인 행만 읽게 해서 막았습니다(`supabase/migrations/*_hand_secrets.sql`).

### 4. 밸런스 시뮬레이터
화면 없이 수천 판을 돌려 족보별 소환 분포, 영웅 조각 획득량, 웨이브 난이도를 확인합니다(`npm run sim`).
결과 리포트는 `design/`에 있습니다.

### 5. 테스트
26개 파일, **447개 테스트**로 족보 판정·전투·베팅·시너지·결정론 재생·DB 스키마를 검증합니다.

## 기술 스택

`TypeScript` `Phaser 3` `Vite` `Supabase (PostgreSQL · RLS · Edge Functions)` `Capacitor (Android)` `AdMob` `Vitest`

## 구조

```
src/
  systems/   순수 게임 로직 (족보 판정, 전투, 베팅, 시너지, 시드, 입력 로그) — Phaser import 금지
  scenes/    Phaser 씬 (로비, 게임, 매칭, 친구 대전, 관전, 랭킹)
  ui/        HUD, 카드 패, 스와이프 패널, 도감
  net/       온라인 대전 클라이언트, 서버 검증 진입점
  data/      유닛·족보·시너지·웨이브·랭킹 수치 (JSON)
supabase/    마이그레이션, Edge Function
scripts/     밸런스 시뮬레이터, 리포트 생성기
tests/       Vitest
```

## 실행

```bash
npm install
npm run dev        # 웹에서 플레이 (오프라인 캠페인은 서버 없이 동작)
npm test           # 테스트
npm run sim        # 밸런스 시뮬레이션
```

온라인 대전을 쓰려면 `.env.example`을 `.env.local`로 복사하고 본인 Supabase 프로젝트 값을 넣으세요(`docs/server-setup.md`).
